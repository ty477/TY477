### 01. Intelligent Fault Diagnosis / 智能故障诊断

Exploring robust diagnosis workflows for rotating machinery by combining signal processing, feature representation, and data-driven learning.

`Rolling Bearing` `CNN` `SVM` `Feature Extraction` `Signal Processing` `Domain Adaptation`

### 02. Embedded Intelligent Monitoring / 嵌入式智能监测

Designing real-time acquisition and edge-processing systems that connect sensors, microcontrollers, and wireless links.

`STM32` `ARM Cortex-M` `MPU6050` `LoRa` `Embedded C` `Real-time Acquisition`

### 03. Aerospace Health Management / 航天装备健康管理

Investigating multi-source sensing, health assessment, and decision support for complex aerospace equipment.

`Sensor Fusion` `Fault Features` `Health Assessment` `Prognostics` `Decision Support`
